# プロジェクト概要: Cluster Trigger Tool

## 目的
Clusterというサービスで使用するトリガーのJSONファイルを簡単に生成・編集するためのWebツールを提供することです。ユーザーはGUIを通じてトリガーの設定を行い、それをJSONファイルとしてエクスポートできます。

## 主要機能
1. **トリガーの作成と編集**
   - 表示名、カテゴリー、確認ダイアログの表示有無、色の設定
   - 状態（state）の追加・編集・削除・並べ替え

2. **JSONファイルの操作**
   - 設定したトリガーをJSONファイルとしてエクスポート
   - 既存のJSONファイルをインポートして編集

3. **ユーザーインターフェース**
   - 直感的なカード形式のUI
   - ドラッグ＆ドロップによる並べ替え
   - カラーピッカーによる色の選択

## 技術スタック
- Next.js (React)
- TypeScript
- Material UI
- Emotion (CSS-in-JS)
- Formik (フォーム管理)

## 対象ユーザー
- Clusterのコンテンツ制作者
- トリガーJSONファイルを手動で編集したくないユーザー

## 成功指標
- ユーザーがGUIを通じて簡単にトリガーJSONを作成できること
- 既存のJSONファイルを読み込んで編集できること
- 直感的なUIでトリガーの設定が行えること
