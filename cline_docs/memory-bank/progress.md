## 既知の問題
1. **大量データ処理時のパフォーマンス**
   - 多数のトリガーや状態を含むJSONファイルの処理時にパフォーマンスが低下する

2. **モバイル対応の不足**
   - 小さな画面サイズでのUIの最適化が不十分

3. **エラーハンドリングの不足**
   - 無効なJSONファイルのインポート時のエラーハンドリングが不十分
   - ユーザーに対するエラーメッセージが不明確

4. **アクセシビリティの問題**
   - スクリーンリーダーなどの支援技術への対応が不十分
   - キーボードナビゲーションのサポートが限定的
